# lamborghini-_sales---dataset
Power BI Lamborghini Sales Analytics sample data, SQL queries, images, and project resources.

## 📊 Project Overview

The Lamborghini Sales Analytics Dashboard is a Power BI data visualization project created to analyze automotive sales performance across four Lamborghini models:

- Countach
- Huracan
- Aventador
- Urus

The project transforms structured sales data into a visually engaging business intelligence dashboard with model-level analysis, sales trends, customer metrics, deal-size analysis, paint-color performance, and global sales distribution.

---

## 🚗 Dashboard Features

### Key Performance Indicators

- Total Sales
- Total Orders
- Total Customers

### Sales Analysis

- Sales by Year
- Sales by Paint Color
- Sales by Deal Size
- Sales by Country
- Model-level sales analysis

### Model Analysis

The dashboard contains dedicated analysis for:

- Lamborghini Countach
- Lamborghini Huracan
- Lamborghini Aventador
- Lamborghini Urus

Each model uses its own visual theme and dynamically displays the relevant sales information.
